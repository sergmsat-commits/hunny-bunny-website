# Замеры «после» — 19.10.2026

Условия те же, что и для замеров «до» (`docs/before/`): Lighthouse 12, локальная сборка (`astro preview`, localhost:4321), симуляция мобильного устройства (Moto G Power, медленный 4G) и отдельный замер десктопа (`--preset=desktop`). Скриншоты: 430×932 @2x (мобильный) и 1440×900 (десктоп), баннер cookies скрыт.
